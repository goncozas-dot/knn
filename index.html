Los dos desarrollos

Ambos usan K-Nearest Neighbors (KNN) para clasificar un caso a partir de sus variables.

Desarrollo 01 · Experiencia del cliente

Satisfaccion con el servicio

Estima si un cliente estaria satisfecho considerando su experiencia de atencion y el valor percibido.

Variables de entrada

  • Calificacion del servicio Escala de 1 a 5
  • Tiempo de espera Minutos
  • Problema resuelto Si = 1 · No = 0
  • Amabilidad del personal Escala de 1 a 5
  • Relacion precio-calidad Escala de 1 a 5
Clasificacion No satisfecho / Satisfecho
Como se genera la etiqueta de demostracion

Se calcula un puntaje: 2 × calificacion + 3 × problema resuelto + amabilidad + relacion precio-calidad − 2 si la espera es de 20 minutos o mas − 2 si es de 45 minutos o mas. Puntaje de 15 o mas: satisfecho. Los datos se generan con combinaciones sinteticas de los valores usados por el programa.

Desarrollo 02 · Automatizacion de precios

Inversion en software

Estima si un empresario invertiria en un software para automatizar la fijacion de precios.

Variables de entrada

  • Presupuesto mensual Soles (S/)
  • Numero de empleados Personas
  • Tiempo dedicado a precios Horas al mes
  • Errores de precios Errores al mes
  • Ahorro estimado Porcentaje
  • Costo del software Soles (S/)
Clasificacion No invertiria / Invertiria
Como se genera la etiqueta de demostracion

La etiqueta positiva requiere que el presupuesto mensual sea igual o mayor al costo del software y que exista al menos una necesidad: ahorro estimado de 20% o mas, 20 horas o mas dedicadas a precios, o 3 errores o mas al mes. El numero de empleados tambien forma parte de las entradas del modelo.

Como funciona el metodo

El mismo flujo de entrenamiento y evaluacion se aplica a los dos problemas.

01

Datos sinteticos

El programa crea combinaciones de ejemplo y asigna etiquetas con reglas simples para cada caso.

02

Escalado y KNN

StandardScaler normaliza las variables y KNN compara cada caso con 5 vecinos, ponderados por distancia.

03

Evaluacion

Se reserva el 25% para prueba y se muestran exactitud, reporte de clasificacion y matriz de confusion.

!
Alcance de los resultados

Los conjuntos son datos sinteticos de demostracion, no registros de clientes ni empresarios reales. Las metricas no representan desempeno en datos reales. Para un uso fiable, hay que entrenar y evaluar con datos reales etiquetados.
